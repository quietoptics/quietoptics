One way this fools people

If you check this after every session and stop as soon as the number finally looks good, you will cross the line by luck eventually. That isn't a signal. That's shopping for one.

Decide how many sessions you're running before you start, run all of them, then look once at the end. It is the least fun rule in practice work and the only one that makes the answer mean anything.

What this does and doesn't tell you

It tells you whether a run of hits is unusual for the pool size you were working with. That is all. It can't tell you why a run is unusual, and one good run is not a result. What settles it is a long record kept honestly, scored the same way every time, including the sessions you'd rather forget.

Maybe it's noise. Maybe it isn't. This is how you'd actually find out.
